# SQL Data Cleaning Project

## Overview

This project demonstrates my SQL data cleaning skills using a messy café sales dataset. The objective was to transform raw data into a clean, consistent, and analysis-ready dataset by applying practical data cleaning techniques in SQL.

## Data Cleaning Tasks

* Renamed columns using the **snake_case** naming convention.
* Standardized text values by trimming whitespace and normalizing invalid entries.
* Replaced missing or invalid categorical values with **"Unknown"**.
* Calculated missing numeric values using related columns where possible.
* Preserved data consistency while preparing the dataset for analysis.

## Data Quality Notes

Some records contained missing **Transaction Date** values. Since there was no reliable information available to infer the correct dates, these values were intentionally left as **NULL** rather than being replaced with fabricated data. This follows a common data-cleaning best practice of preserving data integrity when missing values cannot be accurately recovered.
